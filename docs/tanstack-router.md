# TanStack Router File-Based Routing

This application uses **TanStack Router** with file-based routing.

## Route Structure

Routes are defined in `src/app/routePaths/` and auto-generate a route tree at `src/app/routeTree/routeTree.gen.ts`.

### File Naming Conventions

- `__root.tsx` - Root layout route
- `index.tsx` - Index route at `/`
- `about.tsx` - Static route at `/about`
- `$paramName.tsx` - Dynamic segment (e.g., `greetings.$id.tsx` → `/greetings/:id`)
- `*.lazy.tsx` - Code-split component paired with route config

### Route Configuration Pattern

Each route consists of two files:

1. **Route Config** (`route.tsx`) - Defines path, validation, loaders
2. **Lazy Component** (`route.lazy.tsx`) - Code-split component

#### Example: Index Route with Search Params

**src/app/routePaths/index.tsx**
```typescript
import { createFileRoute } from '@tanstack/react-router';
import * as v from 'valibot';

const searchSchema = v.object({
  lang: v.optional(v.string()),
});

type SearchSchema = v.InferOutput<typeof searchSchema>;

export const Route = createFileRoute('/')({
  validateSearch: (search): SearchSchema => v.parse(searchSchema, search),
});
```

**src/app/routePaths/index.lazy.tsx**
```typescript
import { createLazyFileRoute } from '@tanstack/react-router';

export const Route = createLazyFileRoute('/')({
  component: HomePage,
});

function HomePage() {
  const { lang = 'all' } = Route.useSearch();
  // Component implementation
}
```

## Search Parameter Validation

Use **Valibot** schemas for type-safe search parameter validation:

```typescript
const searchSchema = v.object({
  page: v.optional(v.pipe(v.string(), v.transform(Number))),
  filter: v.optional(v.string()),
});

type SearchSchema = v.InferOutput<typeof searchSchema>;

export const Route = createFileRoute('/list')({
  validateSearch: (search): SearchSchema => v.parse(searchSchema, search),
});
```

## Navigation

Use TanStack Router's typed navigation:

```typescript
import { useNavigate } from '@tanstack/react-router';

const navigate = useNavigate();

// Navigate with params
navigate({ to: '/greetings/$id', params: { id: '123' } });

// Navigate with search
navigate({ to: '/', search: { lang: 'en' } });

// Clear optional search params with undefined
navigate({ to: '/', search: undefined });
```

## Route Tree Generation

The route tree is auto-generated by the TanStack Router Vite plugin. **Never hand-edit** `routeTree.gen.ts`.

To regenerate manually:
```bash
npx tsr generate
```

## Adding a New Route

1. Create route config: `src/app/routePaths/my-route.tsx`
2. Create lazy component: `src/app/routePaths/my-route.lazy.tsx`
3. Route tree regenerates automatically on dev server restart
